# Behance MCP Integration & Validation

Your task is to integrate the following MCP server into this project and ensure it is fully functional.

MCP Server:
https://glama.ai/mcp/servers/Arnonfr/behance-mcp-server

## Primary Goal

Configure this Behance MCP so you can directly interact with my Behance profile and projects from within Cursor.

This MCP will become the primary content source for my portfolio website.

---

## Requirements

1. Install and configure the Behance MCP according to its official documentation.
2. Register the MCP with Cursor using the recommended configuration method.
3. Install every required dependency.
4. Ensure there are no missing environment variables or configuration issues.
5. If authentication is required, explain exactly what I need to provide instead of hardcoding credentials.
6. Verify the MCP starts successfully without errors.
7. Verify Cursor can discover every exposed MCP tool.
8. Produce a short validation report showing:

   * Available tools
   * MCP status
   * Version
   * Any warnings

---

## Functional Validation

After installation, test that the following capabilities work (if supported by the MCP):

* Search Behance projects
* Fetch project details from a Behance project URL
* Retrieve profile information
* Retrieve project metadata
* Retrieve project descriptions
* Retrieve project tags
* Retrieve tools used
* Retrieve cover images
* Retrieve gallery images

Do not assume these work—actually test them if possible.
